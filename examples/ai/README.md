# AI examples

- `context-window.ts` — prompt-budget composition and truncation
- `kv-cache.ts` — token-by-token key/value-cache occupancy
- `neural-networks.ts` — semantic weighted forward propagation
- `next-token-distribution.ts` — temperature, top-k, top-p, and entropy
- `normalization.ts` — per-token layer normalization
- `self-attention-lesson.ts` — trace-driven self-attention
- `tensor-operations.ts` — semantic tensor transformations
- `tensor-semantics.ts` — QKᵀ, scaling, masking, and softmax
- `tensor-slicing.ts` — stable identities across tensor views
- `transformer-attention.ts` — transformer-block composition and focus

Run one with `npx tsx ai/<name>.ts --preview` from this `examples` directory. The gallery runner discovers this folder recursively.
