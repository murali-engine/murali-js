# API areas

Murali's public API is organized into focused package subpaths:

| Area | Import path | Purpose |
| --- | --- | --- |
| Core | `murali-js/core` | Scenes, timelines, cameras, and deterministic state |
| Primitives | `murali-js/primitives` | Shapes, paths, props, and foundational geometry |
| Text | `murali-js/text` | Labels, 3D text, and text/formula morphing |
| Maths | `murali-js/maths` | Graphs, matrices, fields, surfaces, and notation |
| AI | `murali-js/ai` | Neural networks, tensors, attention, and model diagrams |
| Storytelling | `murali-js/storytelling` | Openings, stepwise stories, chat, and celebrations |
| Composite | `murali-js/composite` | Reusable authored components and branded elements |

Detailed API references will be added after the public interfaces stabilize.
